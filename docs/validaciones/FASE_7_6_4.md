# Fase 7.6.4 - Primera captura web automática, local y supervisada
Implementación piloto: botón de captura junto a las escenas. Requiere elegir el origen Página web y analizar primero el sitio; captura una imagen estática de la URL original para incorporarla solo a la escena seleccionada. La imagen se revisa en una vista previa y el usuario confirma su incorporación. No se realizan clics ni se infieren rutas de navegación. JavaScript deshabilitado, recursos externos bloqueados y URL HTTPS pública comprobada; no publicar el servicio en Internet. La comprobación DNS y la conexión del navegador todavía no están fijadas criptográficamente a la misma IP: requiere aislamiento adicional antes de publicar o capturar sitios desconocidos.
Instalación local adicional: `npm install`, luego `npx playwright install chromium`. El proceso de capturas necesita Playwright en dependencias. Solo capturas de la URL pública indicada, no permite páginas internas ni autenticación.
Pruebas: npm test, validar imagen previa, incorporación manual aprobada, volver a aprobar storyboard y renderizar MP4. La captura estática es una mejora de automatización de assets, no una demo navegada. Limitaciones: SPA con JavaScript, páginas con protección antibot, acceso privado, screenshot de páginas completas y capturas por sección.
