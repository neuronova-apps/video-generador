# Editor manual v2 - proyectos portables

El nuevo editor permite guardar un JSON portátil que incluye los archivos originales de imagen y video como datos codificados, y volver a abrirlo recuperando los medios y la línea de tiempo. Límite total: 35 MiB de medios; archivo del proyecto a importar hasta 52 MiB. Se conserva el editor anterior y la exportación WebM piloto, sin audio.

Validación pendiente en Windows: importar una imagen y un video, crear dos clips, modificar textos y tiempos, guardar proyecto con medios, recargar la página, abrir el JSON, comprobar que ambas imágenes/videos y las ediciones se restablecen y exportar WebM. El proyecto no incluye audio independiente ni produce MP4. Los archivos grandes pueden agotar la memoria del navegador. No subir contenido sensible sin revisar el destino de almacenamiento.
