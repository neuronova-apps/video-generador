# Fase 7.6.5 - Movimientos guiados sobre capturas

Se incorporaron movimientos seleccionables por escena: estático, acercamiento, desplazamiento izquierdo y derecho. El movimiento se aplica al recurso visual aportado o capturado, con duración asociada a la escena. Los cambios de movimiento invalidan la aprobación anterior del storyboard y requieren revisión.

Esto no es todavía una demostración automática de navegación, clics o desplazamiento de página: se trata de movimiento de cámara simulado sobre una captura estática. No se agrega narración ni audio.

Validación pendiente: renderizar con imágenes y distintos movimientos, revisar que no se oculten textos ni aparezcan pantallas negras y verificar el movimiento en fotogramas consecutivos. Se mantiene el servicio local para capturas, no apto para producción pública.
